۲. فضای برداری

فضای برداری — تعریف

فضای برداری $V$ روی میدان $\mathbb{F}$ با ۸ اصل:

اصول جمع
  • ۱. $\vec{u} + \vec{v} = \vec{v} + \vec{u}$
  • ۲. $(\vec{u}+\vec{v})+\vec{w} = \vec{u}+(\vec{v}+\vec{w})$
  • ۳. $\exists \vec{0}$
  • ۴. $\exists (-\vec{u})$
اصول ضرب اسکالر
  • ۵. $c(\vec{u}+\vec{v}) = c\vec{u}+c\vec{v}$
  • ۶. $(c+d)\vec{u} = c\vec{u}+d\vec{u}$
  • ۷. $c(d\vec{u}) = (cd)\vec{u}$
  • ۸. $1 \cdot \vec{u} = \vec{u}$
۲. زیرفضا

زیرفضای برداری

سه شرط کافی برای زیرفضا:

$$\text{۱. } \vec{0} \in W$$ $$\text{۲. } \vec{u}, \vec{v} \in W \Rightarrow \vec{u}+\vec{v} \in W$$ $$\text{۳. } \vec{u} \in W, c \in \mathbb{F} \Rightarrow c\vec{u} \in W$$

۶. هسته و تصویر

هسته، تصویر و رتبه-پوچی

هسته (Kernel / Null Space)
$$\ker(T) = \{\vec{v} : T(\vec{v}) = \vec{0}\}$$
تصویر (Image / Column Space)
$$\text{Im}(T) = \{\vec{w} : \exists \vec{v}, T(\vec{v}) = \vec{w}\}$$
قضیه رتبه-پوچی
$$\text{rank}(T) + \text{nullity}(T) = \dim(V)$$

سوال کلیدی

کدام بردارها هنگام اعمال $A$، به صفر می‌روند؟

تعریف
$$\text{Null}(A) = \{\vec{x} \in \mathbb{R}^n : A\vec{x} = \vec{0}\}$$
مثال
$$A = \begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}$$ $$\text{Null}(A) = \text{span}\left\{ \begin{pmatrix} -2 \\ 1 \end{pmatrix} \right\}$$

۶. شبه‌معکوس

شبه‌معکوس Moore-Penrose

MP (Moore-Penrose Pseudo-Inverse) تعمیم معکوس برای ماتریس‌های غیرمربعی.

چهار شرط
$$A A^+ A = A$$ $$A^+ A A^+ = A^+$$ $$(A A^+)^T = A A^+$$ $$(A^+ A)^T = A^+ A$$
محاسبه با SVD
$$A = U \Sigma V^T \;\Longrightarrow\; A^+ = V \Sigma^+ U^T$$

Condition Number — مریضی ماتریس

cond(A) (Condition Number) معیاری از حساسیت ماتریس.

تعریف
$$\text{cond}(A) = \|A\| \cdot \|A^{-1}\| = \frac{\sigma_{\max}}{\sigma_{\min}}$$
cond ≈ 1

۹. بُعد فضاها

بُعد چهار فضای بنیادی

برای $A \in \mathbb{R}^{m \times n}$ با رتبه $r$:

زیرفضاهای $\mathbb{R}^n$
$$\dim(\text{Row}(A)) = r, \quad \dim(\text{Null}(A)) = n - r$$
زیرفضاهای $\mathbb{R}^m$
$$\dim(\text{Col}(A)) = r, \quad \dim(\text{Null}(A^T)) = m - r$$
