چرا نانو انبرک مهم است؟

در مقیاس نانو، نیروهای سطحی (الکترواستاتیک، واندروالس، کازیمیر) غالب می‌شوند و رفتار سیستم کاملاً غیرخطی می‌شود. این پدیده، پایه میکروسکوپ نیروی اتمی (AFM)، سنسورهای زیستی، و رزوناتورهای MEMS/NEMS است.

مقیاس‌ها

نیروهای غالب در مقیاس‌های مختلف

مقیاس ماکرو (mm-m)

نیروی غالب: گرانش
$F \propto L^3$

مقیاس میکرو (μm)

نیروی غالب: الکترواستاتیک
$F \propto L^2 / g^2$

مقیاس نانو (nm)

نیروی غالب: واندروالس / کازیمیر
$F \propto 1/g^n$

نکته کلیدی: با کوچک شدن مقیاس، نسبت سطح به حجم افزایش می‌یابد و نیروهای سطحی بر نیروهای حجمی (مثل گرانش) غالب می‌شوند.
نیرو ۱

نیروی الکترواستاتیک (Electrostatic Force)

فرمول نیروی الکترواستاتیک

برای دو صفحه موازی با فاصله $g$ و اختلاف پتانسیل $V$:

$$F_{es} = \frac{\epsilon_0 A V^2}{2 g^2}$$
  • 🔹 $\epsilon_0 = 8.85 \times 10^{-12}$ F/m (گذردهی خلأ)
  • 🔹 $A$ = سطح مقطع (m²)
  • 🔹 $V$ = ولتاژ اعمالی (V)
  • 🔹 $g$ = فاصله اولیه (m)
نکته: غیرخطی بودن

وقتی تیر خم می‌شود، فاصله کاهش می‌یابد ($g \to g - w$):

$$F_{es} = \frac{\epsilon_0 A V^2}{2(g - w)^2}$$
نیرو ۲

نیروی واندروالس (Van der Waals Force)

فرمول نیروی واندروالس

برای دو سطح موازی در فاصله $g$:

$$F_{vdW} = \frac{A_H b}{6\pi (g - w)^3}$$
  • 🔹 $A_H$ = ثابت هاماکر ($\sim 10^{-19}$ J)
  • 🔹 $b$ = عرض تیر (m)
  • 🔹 $(g - w)^3$ = وابستگی مکعبی به فاصله

نیرو ۳

نیروی کازیمیر (Casimir Force)

فرمول نیروی کازیمیر

برای فاصله‌های بزرگ‌تر (معمولاً > ۱۰۰ nm):

$$F_{cas} = \frac{\pi^2 \hbar c \, b}{240 (g - w)^4}$$
  • 🔹 $\hbar$ = ثابت پلانک کاهش‌یافته
  • 🔹 $c$ = سرعت نور
  • 🔹 $(g-w)^4$ = وابستگی مرتبه ۴
تفاوت کازیمیر و واندروالس
  • 🔹 واندروالس: نیروی بین‌مولکولی کلاسیک — $1/g^3$
  • 🔹 کازیمیر: نیروی کوانتومی ناشی از نوسانات خلأ — $1/g^4$
  • 🔹 در فاصله‌های بزرگ، کازیمیر غالب است
کشف کازیمیر (۱۹۴۸): هندریک کازیمیر پیش‌بینی کرد که دو صفحه فلزی موازی در خلأ، به‌دلیل نوسانات کوانتومی خلأ، یکدیگر را جذب می‌کنند. این پدیده در سال ۱۹۹۷ تجربی تأیید شد.
استخراج PDE

استخراج PDE غیرخطی نانو انبرک

گام ۱: تعادل نیرو
$$EI \frac{\partial^4 w}{\partial x^4} = F_{es} + F_{vdW} + F_{cas}$$
گام ۲: PDE کامل
$$EI \frac{\partial^4 w}{\partial x^4} = \frac{\epsilon_0 b V^2}{2(g-w)^2} + \frac{A_H b}{6\pi (g-w)^3} + \frac{\pi^2 \hbar c \, b}{240 (g-w)^4}$$
گام ۳: شرایط مرزی
  • 🔹 در $x=0$: $w = 0$، $w' = 0$
  • 🔹 در $x=L$: $w'' = 0$، $w''' = 0$
ویژگی کلیدی: PDE نانو انبرک غیرخطی است (به‌دلیل $(g-w)^n$ در مخرج). برای حل آن به روش‌های خاص مثل Perturbation یا PINN نیاز داریم.
بی‌بعدسازی

نرمال‌سازی معادله

تعریف متغیرهای بی‌بعد
$$\hat{w} = \frac{w}{g}, \quad \hat{x} = \frac{x}{L}, \quad \hat{t} = \frac{t}{T_0}$$

با $T_0 = \sqrt{\rho A L^4 / EI}$.

معادله بی‌بعد
$$\frac{\partial^4 \hat{w}}{\partial \hat{x}^4} = \frac{\alpha V^2}{(1-\hat{w})^2} + \frac{\beta}{(1-\hat{w})^3} + \frac{\gamma}{(1-\hat{w})^4}$$
  • 🔹 $\alpha = \frac{\epsilon_0 b L^4}{2 g^3 EI}$ (پارامتر الکترواستاتیک)
  • 🔹 $\beta = \frac{A_H b L^4}{6\pi g^4 EI}$ (پارامتر واندروالس)
  • 🔹 $\gamma = \frac{\pi^2 \hbar c \, b L^4}{240 g^5 EI}$ (پارامتر کازیمیر)
مزیت بی‌بعدسازی: تعداد پارامترها کم می‌شود و رفتار عمومی سیستم با ۳ پارامتر $(\alpha, \beta, \gamma)$ توصیف می‌شود.
حالت استاتیک

کاهش به ODE مرتبه ۴

ODE استاتیک
$$\frac{d^4 \hat{w}}{d \hat{x}^4} = \frac{\alpha V^2}{(1-\hat{w})^2} + \frac{\beta}{(1-\hat{w})^3}$$
روش‌های حل
  • 🔹 روش تفاضل محدود: گسسته‌سازی + حل عددی
  • 🔹 روش Perturbation: بسط سری توانی
  • 🔹 روش Galerkin: تصویر روی توابع پایه
  • 🔹 روش PINN: شبکه عصبی با قید PDE
چالش اصلی

غیرخطی بودن معادله باعث می‌شود حل تحلیلی وجود نداشته باشد و رفتار سیستم پیچیده شود — به همین دلیل از روش‌های تقریبی استفاده می‌کنیم.

پایداری

پدیده Pull-in

تعریف Pull-in

وقتی ولتاژ از یک مقدار بحرانی $V_{pull-in}$ فراتر رود، نیروی الکترواستاتیک بر سختی مکانیکی غلبه می‌کند و تیر ناگهانی به سمت بستر کشیده می‌شود.

ولتاژ Pull-in
$$V_{pull-in} = \sqrt{\frac{8 k_{eq} g^3}{27 \epsilon_0 A}}$$

که $k_{eq} = 8EI/L^4$ (سختی معادل تیر یک‌سر گیردار با بار توزیع‌شده).

کاربرد Pull-in
  • 🔹 سوییچ‌های RF: Pull-in = حالت ON/OFF
  • 🔹 سنسور فشار: تشخیص آستانه
  • 🔹 حافظه NEMS: ذخیره بیت
Perturbation

حل با روش Perturbation

ایده اصلی

اگر $\epsilon$ کوچک باشد، جواب را به‌صورت سری توانی می‌نویسیم:

$$\hat{w}(\hat{x}) = \hat{w}_0 + \epsilon \hat{w}_1 + \epsilon^2 \hat{w}_2 + \cdots$$
مراحل
  • 🔹 مرتبه صفر: حل خطی (بدون نیروهای نانو)
  • 🔹 مرتبه اول: اعمال نیروی الکترواستاتیک
  • 🔹 مرتبه دوم: اعمال واندروالس
  • 🔹 جمع جواب‌ها: حل تقریبی نهایی
محدودیت: روش Perturbation فقط برای $\epsilon$ کوچک معتبر است. برای ولتاژهای نزدیک Pull-in، اعتبار خود را از دست می‌دهد — اینجاست که PINN وارد می‌شود.
کد

حل عددی نانو انبرک

% === حل عددی نانو انبرک با تفاضل محدود ===
clear; clc; close all;

% پارامترها
L = 50e-6;          % طول (m)
b = 5e-6;           % عرض (m)
h = 0.5e-6;        % ضخامت (m)
g = 200e-9;        % فاصله (m)
E = 150e9;         % مدول یانگ (Pa)
eps0 = 8.85e-12;  % گذردهی خلأ
V = 5;              % ولتاژ (V)

I = b*h^3/12;

% === حل عددی با تکرار ===
N = 100;
dx = L/(N-1);
x = linspace(0, L, N);
w = zeros(1, N);

tol = 1e-9;
maxIter = 500;

for iter = 1:maxIter
    w_old = w;
    for i = 3:N-2
        F_es = eps0*b*V^2 / (2*(g-w(i))^2);
        w(i) = (F_es*dx^4/E/I + 4*w(i-1) - 6*w(i) + 4*w(i+1) - w(i+2))/1;
    end
    if max(abs(w - w_old)) < tol
        fprintf('همگرایی در %d تکرار\n', iter);
        break;
    end
end

plot(x*1e6, w*1e9, 'linewidth', 2);
xlabel('x (μm)'); ylabel('w (nm)');
title('خمش نانو انبرک');
grid on;
# === حل عددی نانو انبرک ===
import numpy as np
import matplotlib.pyplot as plt

# پارامترها
L = 50e-6; b = 5e-6; h = 0.5e-6
g = 200e-9; E = 150e9; eps0 = 8.85e-12; V = 5
I = b*h**3/12

# حل عددی
N = 100
dx = L/(N-1)
x = np.linspace(0, L, N)
w = np.zeros(N)

for it in range(500):
    w_old = w.copy()
    for i in range(3, N-2):
        F_es = eps0*b*V**2 / (2*(g-w[i])**2)
        w[i] = (F_es*dx**4/E/I + 4*w[i-1] - 6*w[i] + 4*w[i+1] - w[i+2])
    if np.max(np.abs(w - w_old)) < 1e-9:
        print(f'همگرایی در {it+1} تکرار')
        break

plt.plot(x*1e6, w*1e9, linewidth=2, color='#00d4aa')
plt.xlabel('x (μm)'); plt.ylabel('w (nm)')
plt.title('خمش نانو انبرک')
plt.grid(True, alpha=0.3)
plt.savefig('nano_cantilever.png', dpi=600, bbox_inches='tight')
plt.show()

اصل کار

  • 🔹 نیروی واندروالس بین نوک و سطح → خمش
  • 🔹 لیزر خمش را اندازه می‌گیرد
  • 🔹 تصویر با دقت اتمی ساخته می‌شود
حساسیت
  • 🔹 دقت عمودی: ۰.۱ Å
  • 🔹 دقت افقی: ۱ nm
  • 🔹 نیروی تشخیص: pN
کاربردهای AFM: تصویربرداری از DNA، پروتئین‌ها، نانومواد، سلول‌ها، و اندازه‌گیری نیروهای بین‌مولکولی تک‌مولکولی.
PINN

تخمین پارامترها با PINN

در نانو انبرک، پارامترهای $\alpha$, $\beta$, $\gamma$ ممکن است نامعلوم باشند. PINN می‌تواند آن‌ها را از داده‌های خمش تخمین بزند.

تابع هزینه
$$\mathcal{L} = \left\|\frac{d^4 \hat{w}}{d\hat{x}^4} - \frac{\alpha V^2}{(1-\hat{w})^2} - \frac{\beta}{(1-\hat{w})^3}\right\|^2 + \lambda \|\hat{w}_{data}\|^2$$
مسئله مستقیم

$\alpha, \beta$ معلوم — خمش $\hat{w}$ را پیش‌بینی کن.

مسئله معکوس

$\alpha, \beta$ نامعلوم — از داده‌های خمش تخمین بزن.

اتصال به پروژه پایانی: نانو انبرک یکی از موضوعات پیشنهادی است که با Perturbation + PINN حل می‌شود.

الف
سؤالات مفهومی
  1. چرا در مقیاس نانو، نیروهای سطحی بر نیروهای حجمی غالب می‌شوند؟

تمرین‌های عملی
  1. ولتاژ Pull-in یک نانو انبرک سیلیکونی با $L=100$ μm، $b=10$ μm، $h=1$ μm و $g=500$ nm را محاسبه کنید.
  2. کد MATLAB نانو انبرک را اجرا کنید و اثر ولتاژ را بررسی کنید.
  3. با تغییر فاصله $g$، ولتاژ Pull-in را رسم کنید.
  4. اثر نیروی واندروالس بر ولتاژ Pull-in را تحلیل کنید.
ج
تمرین‌های نوشتاری
  1. PDE نانو انبرک را از تعادل نیرو استخراج کنید.
  2. با بی‌بعدسازی، پارامترهای $\alpha$, $\beta$ را استخراج کنید.
  3. ولتاژ Pull-in را برای تیر یک‌سر گیردار با استفاده از روش انرژی محاسبه کنید.
★
