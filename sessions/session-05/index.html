تقریباً تمام پدیده‌های فیزیکی در مکاترونیک با PDE توصیف می‌شوند: انتقال حرارت، ارتعاشات، الکترواستاتیک، دینامیک سیالات، و دینامیک سازه.

۲. تعریف

PDE چیست؟ تفاوت با ODE

PDE — Partial Differential Equation

معادله دیفرانسیل جزئی — شامل دو یا چند متغیر مستقل:

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$$

🔍 متغیرها: $x$ (مکان)، $t$ (زمان)، $u(x,t)$ (دما)

ODE — Ordinary Differential Equation

معادله دیفرانسیل معمولی — شامل یک متغیر مستقل:

$$m\ddot{x} + c\dot{x} + kx = F(t)$$

🔍 متغیر: $t$ (زمان)، $x(t)$ (موقعیت)

پیشگامان این حوزه
Joseph Fourier
(1768–1830)
ریاضیدان و فیزیکدان فرانسوی. با مطالعه انتقال حرارت، پایه سری فوریه و تبدیل فوریه را بنا نهاد.
John von Neumann
(1903–1957)
ریاضیدان مجارستانی-آمریکایی. پیشگام تحلیل پایداری عددی PDE و معماری کامپیوتر.
۳. دسته‌بندی

دسته‌بندی PDE

مرتبه (Order)
  • 🔹 مرتبه اول: بالاترین مشتق = ۱
  • 🔹 مرتبه دوم: بالاترین مشتق = ۲
  • 🔹 مرتبه n: بالاترین مشتق = n
$$u_t + c u_x = 0 \text{ (مرتبه ۱)}$$ $$u_{tt} = c^2 u_{xx} \text{ (مرتبه ۲)}$$
خطی بودن (Linearity)
  • 🔹 خطی (Linear): توان ۱ در $u$
  • 🔹 نیمه‌خطی (Semi-linear): ضرایب وابسته
  • 🔹 غیرخطی (Nonlinear): توان بالاتر
$$u_t = u_{xx} \text{ (خطی)}$$ $$u_t = u \cdot u_x \text{ (غیرخطی)}$$
همگن (Homogeneous) و ناهمگن (Non-homogeneous)

همگن: $L[u] = 0$ — ناهمگن: $L[u] = f(x,t)$ (عبارت منبع)

$$u_{tt} - c^2 u_{xx} = 0 \text{ (همگن)}$$ $$u_{tt} - c^2 u_{xx} = F(x,t) \text{ (ناهمگن)}$$
۴. سه نوع اصلی

بیضوی، سهموی، هذلولوی

برای PDE مرتبه دوم خطی به فرم عمومی:

$$A u_{xx} + B u_{xy} + C u_{yy} + \cdots = 0$$

دسته‌بندی بر اساس ممیز $\Delta = B^2 - 4AC$:

بیضوی (Elliptic)

$\Delta < 0$
مثال: لاپلاس

$$u_{xx} + u_{yy} = 0$$
سهموی (Parabolic)

$\Delta = 0$
مثال: گرما

$$u_t = \alpha u_{xx}$$
هذلولوی (Hyperbolic)

$\Delta > 0$
مثال: موج

$$u_{tt} = c^2 u_{xx}$$

۴. مثال ۱ + استخراج

معادله گرما — از کجا می‌آید؟

گام ۱: قانون بقای انرژی

در یک قطعه کوچک از میله با طول $\Delta x$:

$$\text{تغییر انرژی} = \text{شار ورودی} - \text{شار خروجی}$$
گام ۲: قانون فوریه (شار حرارتی)

شار حرارتی متناسب با گرادیان دما:

$$q = -k \frac{\partial u}{\partial x}$$

$k$ = ضریب هدایت حرارتی — علامت منفی: گرما از گرم به سرد می‌رود

گام ۳: ترکیب و حدگیری

با $\Delta x \to 0$:

$$\rho c_p \frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}$$

با تعریف $\alpha = \frac{k}{\rho c_p}$ (ضریب نفوذ حرارتی):

$$\boxed{\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}}$$
کاربرد مکاترونیکی
  • 🔹 انتقال حرارت در عملگر پیزوالکتریک
  • 🔹 خنک‌سازی مدار الکترونیکی
  • 🔹 تحلیل حرارتی موتور
انتشار گرما در میله

معادله موج — از قانون دوم نیوتن

گام ۱: نیروی کشش تار

در یک قطعه کوچک از تار با طول $\Delta x$، نیروی کشش $T$ در دو سر:

$$\sum F_y = T\sin\theta_2 - T\sin\theta_1$$
گام ۲: تقریب زاویه کوچک

برای جابجایی‌های کوچک: $\sin\theta \approx \tan\theta = \frac{\partial u}{\partial x}$

$$\sum F_y \approx T\left[\frac{\partial u}{\partial x}\Big|_{x+\Delta x} - \frac{\partial u}{\partial x}\Big|_{x}\right]$$
گام ۳: قانون دوم نیوتن

$F = ma$ که $m = \rho \Delta x$ و $a = \frac{\partial^2 u}{\partial t^2}$:

$$\rho \Delta x \frac{\partial^2 u}{\partial t^2} = T \Delta x \frac{\partial^2 u}{\partial x^2}$$

با $c = \sqrt{T/\rho}$:

$$\boxed{\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}}$$
نکته کلیدی

این معادله، پایه سازهای زهی (تار، گیتار، ویولن) و همچنین ارتعاش تیر در مکاترونیک است.

۵. شرایط مرزی

شرایط مرزی (Boundary Conditions)

دیریکله (Dirichlet)

مقدار تابع در مرز مشخص است:

$$u(0, t) = u_0$$

📌 مثال: دمای ثابت انتهای میله

نویمان (Neumann)

مشتق تابع در مرز مشخص است:

$$u_x(0, t) = q_0$$

📌 مثال: شار حرارتی ثابت

رابین (Robin)

ترکیب مقدار و مشتق:

$$u_x + h u = q_0$$

📌 مثال: انتقال حرارت جابجایی

۶. اصل برهم‌نهی

اصل برهم‌نهی (Superposition Principle)

برای PDE های خطی و همگن، اگر $u_1$ و $u_2$ جواب باشند، هر ترکیب خطی نیز جواب است:

$$L[u_1] = 0, \quad L[u_2] = 0 \;\Longrightarrow\; L[c_1 u_1 + c_2 u_2] = 0$$

۷. کد

حل عددی PDE ساده

یک PDE ساده را با روش تفاضل محدود (Finite Difference Method) حل می‌کنیم.

% === حل عددی معادله گرما ===
clear; clc; close all;
L = 1; Nx = 50; alpha = 0.01; T = 1; Nt = 1000;
dx = L/(Nx-1); dt = T/Nt;
r = alpha * dt / dx^2;
if r > 0.5
    error('شرط پایداری نقض شده!');
end
x = linspace(0, L, Nx);
u = sin(pi*x);
for n = 1:Nt
    u_new = u;
    for i = 2:Nx-1
        u_new(i) = u(i) + r*(u(i+1) - 2*u(i) + u(i-1));
    end
    u = u_new;
end
plot(x, u, 'linewidth', 2);
import numpy as np
import matplotlib.pyplot as plt
L = 1.0; Nx = 50; alpha = 0.01; T = 1.0; Nt = 1000
dx = L / (Nx - 1); dt = T / Nt
r = alpha * dt / dx**2
if r > 0.5:
    raise ValueError('شرط پایداری نقض شده!')
x = np.linspace(0, L, Nx)
u = np.sin(np.pi * x)
for n in range(Nt):
    u[1:-1] = u[1:-1] + r * (u[2:] - 2*u[1:-1] + u[:-2])
plt.plot(x, u, linewidth=2, color='#ffb700')
plt.savefig('heat.png', dpi=600)

مدل دوچرخه‌ای خودرو (Bicycle Model)

برای تحلیل شتاب جانبی و چرخش (Yaw) خودرو، از مدل ساده‌شده دوچرخه‌ای استفاده می‌شود:

معادلات حرکت
$$m(\dot{v}_y + v_x r) = F_{yf} + F_{yr}$$ $$I_z \dot{r} = l_f F_{yf} - l_r F_{yr}$$
معادله کوپل نهایی
$$\begin{pmatrix} \dot{v}_y \\ \dot{r} \end{pmatrix} = A \begin{pmatrix} v_y \\ r \end{pmatrix} + B \delta$$

$\delta$ = زاویه فرمان

اتصال به Simulink/CarSim

این معادلات در Simulink پیاده‌سازی و در CarSim برای فرمان‌دهی ساده تست می‌شوند.

۷. کاربرد: موسیقی

معادله تار مرتعش و سازهای ایرانی

معادله موج یک‌بعدی، پایه فیزیکی سازهای زهی مانند تار و سه‌تار است:

$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad c = \sqrt{\frac{T}{\rho}}$$

$T$ = کشش تار، $\rho$ = چگالی خطی. فرکانس پایه:

$$f_1 = \frac{c}{2L} = \frac{1}{2L}\sqrt{\frac{T}{\rho}}$$
ساز تار ایرانی

تار از سازهای زهی مضرابی است که با تغییر طول تار (با حرکت دست روی دسته) فرکانس و نُت تغییر می‌کند.

استخراج گام‌به‌گام ضرایب فوریه

سری فوریه: $f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n \cos(n\omega x) + b_n \sin(n\omega x)\right]$

گام ۱: تعامد پایه‌ها
$$\int_{-L}^{L} \sin\!\left(\frac{m\pi x}{L}\right)\sin\!\left(\frac{n\pi x}{L}\right) dx = L\delta_{mn}$$ $$\int_{-L}^{L} \cos\!\left(\frac{m\pi x}{L}\right)\cos\!\left(\frac{n\pi x}{L}\right) dx = L\delta_{mn}$$ $$\int_{-L}^{L} \sin\!\left(\frac{m\pi x}{L}\right)\cos\!\left(\frac{n\pi x}{L}\right) dx = 0$$
گام ۲: ضرب در cos و انتگرال

ضرب دو طرف در $\cos\!\left(\frac{n\pi x}{L}\right)$ و انتگرال از $-L$ تا $L$:

$$\int_{-L}^{L} f(x)\cos\!\left(\frac{n\pi x}{L}\right) dx = \int_{-L}^{L} a_n \cos^2\!\left(\frac{n\pi x}{L}\right) dx$$

← جواب:

$$\boxed{a_n = \frac{1}{L}\int_{-L}^{L} f(x)\cos\!\left(\frac{n\pi x}{L}\right) dx}$$
گام ۳: به‌طور مشابه برای $a_0$ و $b_n$
$$\boxed{a_0 = \frac{1}{L}\int_{-L}^{L} f(x) dx}$$ $$\boxed{b_n = \frac{1}{L}\int_{-L}^{L} f(x)\sin\!\left(\frac{n\pi x}{L}\right) dx}$$
چرا مهم است؟

ضرایب فوریه، تصویر تابع $f$ روی پایه‌های متعامد $\{\cos(n\omega x), \sin(n\omega x)\}$ است — این همان مفهوم فضای برداری است که در جلسه ۳ دیدیم.

تکمیلی

استخراج معادله گرما در ۳ بعد

تعمیم معادله گرما به سه بُعد:

$$\frac{\partial u}{\partial t} = \alpha \left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2}\right) = \alpha \nabla^2 u$$
گام ۱: بقای انرژی در ۳ بعد

برای حجم کوچک $V$ با سطح $\partial V$:

$$\frac{d}{dt}\int_V \rho c_p u \, dV = -\int_{\partial V} \vec{q} \cdot d\vec{A}$$
گام ۲: قضیه واگرایی (Divergence Theorem)
$$\int_V \left[\rho c_p \frac{\partial u}{\partial t} + \nabla \cdot \vec{q}\right] dV = 0$$

چون برای هر حجمی برقرار است:

$$\rho c_p \frac{\partial u}{\partial t} = -\nabla \cdot \vec{q} = \nabla \cdot (k \nabla u)$$
نتیجه نهایی
$$\boxed{\frac{\partial u}{\partial t} = \alpha \nabla^2 u}$$

$\alpha = \frac{k}{\rho c_p}$ = ضریب نفوذ حرارتی
